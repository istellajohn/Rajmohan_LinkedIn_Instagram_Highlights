## How to download

- **Everything:** on GitHub choose Code, then Download ZIP (on the branch you are viewing).
- **One image:** open the file on GitHub and use the download button, or open it and save the image. GitHub shows large PNGs scaled down in the browser, so download the file to get the full resolution.

## File names

`Rajmohan-Krishnan_The-Record_Slide-04_Folio-002_The-Economic-Times_Profile_2026-03-06_Index-M005_READY-TO-POST-2160x3840.png`

- Slide: position in the Highlight, which is the upload order.
- Folio: the number printed on the Story.
- Index-Mnnn: the article's row in `05_Documents/ARTICLE_INDEX_production-control-sheet.md`.
